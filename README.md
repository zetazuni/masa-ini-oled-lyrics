# Masa Ini: OLED Lyrics Video

Time-synced lyrics on the built-in OLED of a **Heltec WiFi LoRa 32 V4**, made to be filmed on a phone for a short video or story. The song is "Masa Ini, Masa Nanti dan Masa Indah Lainnya" by Nuca. The board only shows the lyrics. The music plays from another device.

**Live presentation with a board simulator and the real run video:** https://masa-ini-oled-lyrics.netlify.app

The recorded run (with the music) is in [`documentation/MasaIni_Demo.mp4`](documentation/MasaIni_Demo.mp4). The YouTube upload was blocked by a copyright claim on the song.

## What's in the repo

| Path | What it is |
|---|---|
| `MasaIni_LyricsVideo.ino` | Arduino firmware: state machine, clock, screens |
| `lyrics_timestamps.h` | Lyric table (`struct Lyric`, timings, song length), generated by the stamper and `#include`d by the sketch |
| `MasaIni_Stamper.py` | PC tool to record lyric timings by tapping keys while the song plays |
| `documentation/MasaIni_Presentation.html` | Interactive 5-slide presentation with a working browser simulator of the board. Open it in any browser, next to `MasaIni_Demo.mp4`. |
| `documentation/MasaIni_Demo.mp4` | Web-sized recording of the real run (720p, 86 s) |
| `documentation/Masa_Ini.mp3` | Audio clip the simulator plays. It starts when the countdown ends, at the first lyric. |
| `PROJECT_NOTES.md` | Detailed development notes: architecture, settings, issues fixed, ideas |

## Hardware

- Heltec WiFi LoRa 32 V4 (ESP32-S3R2, SSD1315 128x64 OLED on I2C)
- OLED pins: SDA 17, SCL 18, RST 21. Vext (GPIO 36) is driven LOW to power the display.
- Control: the PRG/BOOT button (GPIO 0)

## Build and upload

Arduino IDE (or `arduino-cli`) with:

- Espressif **esp32** core 3.3.11
- Library **U8g2** (olikraus)
- Board **Heltec WiFi LoRa 32 (V4)**, LoRa FEM Type **GC1109_PA**, USB CDC On Boot **Enabled**

The sketch folder name must match the sketch name, so put `MasaIni_LyricsVideo.ino` and `lyrics_timestamps.h` together in a folder called `MasaIni_LyricsVideo`. Then:

```
arduino-cli compile --fqbn esp32:esp32:heltec_wifi_lora_32_V4:LORA_FEM_TYPE=2,CDCOnBoot=cdc --upload -p COMx MasaIni_LyricsVideo
```

## Use it

1. Edit the `LYRICS` list in `MasaIni_Stamper.py` (one entry per timing event).
2. `pip install pynput`, then `python MasaIni_Stamper.py`.
3. Press **T** when the song starts, **SPACE** at the start of every line, **B** to undo, **Q** to export. This writes `lyrics_timestamps.h` next to the script.
4. Re-flash the board.
5. Put the phone in front of the OLED and cue the song 5 s before the first lyric (1:34 for this song).
6. Press **BOOT** and start the song at the same moment. The first lyric appears 5 s later.

BOOT starts, pauses, resumes and replays. Tuning knobs at the top of the sketch: `PRE_ROLL_MS` (default 5000) and `SYNC_OFFSET_MS` (positive = lyrics later).

## How it works

- **State machine:** `INTRO -> WAITING -> PLAYING <-> PAUSED -> DONE -> PLAYING`.
- **Clock:** `elapsed = millis() - songStart - SYNC_OFFSET_MS`. On BOOT the clock jumps so the first lyric lands `PRE_ROLL_MS` later.
- **Current line:** scan the table backwards for `startMs <= t < endMs`.
- **Line splitting:** long lyrics break at the space that minimises the longer half.
- **Progress bar and header clock:** measured from the first lyric to the end of the song.

More detail and diagrams are in the presentation and in `PROJECT_NOTES.md`.
